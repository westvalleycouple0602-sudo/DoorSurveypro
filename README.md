# DoorSurveypro

The most comprehensive door, frame and hardware opening surveying tool for door and door hardware professionals.

## Open the application source

The application source is currently on **[foundation/existing-app](https://github.com/westvalleycouple0602-sudo/DoorSurveypro/tree/foundation/existing-app)**. This default `main` branch is an entry page while the application import is under review. Downloading `main` does not download the application.

- **[Application import — draft PR #2](https://github.com/westvalleycouple0602-sudo/DoorSurveypro/pull/2)** preserves the existing platform and its engineering foundation.
- **[Build repair and Plan-style interface — draft PR #3](https://github.com/westvalleycouple0602-sudo/DoorSurveypro/pull/3)** targets the application branch. Its source passed the production build in [GitHub run 39163894594](https://github.com/westvalleycouple0602-sudo/DoorSurveypro/actions/runs/39163894594); other application checks remain unresolved.
- **[Repair source](https://github.com/westvalleycouple0602-sudo/DoorSurveypro/tree/fix/portable-build-field-ui)** includes portable dependency downloads, verified local build tools, and field interface styling from Door survey pro Plan.

These are source changes under review, not a live deployment. Existing type-check, unit-test and dependency-audit issues must be resolved before release. Source transfers do not include the live database, object storage or service credentials.
