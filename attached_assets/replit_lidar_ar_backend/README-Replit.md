# Replit Deployment

## Run
- Click **Run**. Replit will install dependencies and start Flask on port 5000.
- Open the **Webview** to interact with the app.

## Useful pages
- Pricing UI: `/public/pricing.html`
- CSV Price Uploader: `/public/price_csv.html`
- Template Generator: `/public/template.html`
- Partner Compare: `/public/compare.html`
- API Docs: `/public/swagger.html`

## Environment variables (optional)
- `SENDGRID_API_KEY` — email fallback for partner quotes
- `BUG_EMAIL_FROM` — from address for SendGrid
