# DoorSurvey AI — All-in-One (Ship-It)

This package includes:
- Compliance rules + amendments + editor
- AI recommendations + BOM/Pro/Ultra + pricing/exports
- Express API (/bom, /quote, /rules, /rules/validate) + static UI (/ and /rules-editor)
- Tests & fixtures

## Run
```bash
npm install
npm run dev
# open http://localhost:3000
```
- Use the **UI** at `/` to run BOM/Quote, and the **Rules Editor** at `/rules-editor` to view/edit rules.
