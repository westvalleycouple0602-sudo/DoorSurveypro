=== Vulnerability Demonstration (Without Patch) ===
Without validation, an attacker could:
  1. Access different Google APIs:
     calendarId: '../../admin/directory/v1/users'
     Would become: https://www.googleapis.com/calendar/v3/calendars/../../admin/directory/v1/users/events/watch
     Resolves to: https://www.googleapis.com/admin/directory/v1/users/events/watch

  2. Exfiltrate data using the OAuth token:
     calendarId: '../../drive/v3/files'
     Could access Google Drive files with stolen credentials

  3. Access unauthorized resources:
     Any Google API endpoint accessible with the OAuth token scope
