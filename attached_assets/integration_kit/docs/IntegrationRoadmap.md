# Integration Roadmap
## Phase 1 — Core (Weeks 0–4)
- HubSpot OAuth + contact sync
- QuickBooks auth + invoice/estimate export
- DocuSign e-sign flow for quotes
- Webhook router + signature verification
- Slack notifications for approvals
- Basic BI export endpoints (CSV)

## Phase 2 — Growth (Weeks 5–10)
- Google/Outlook Calendar scheduling
- Google Drive/Dropbox storage
- Zapier/Make triggers
- Background sync with BullMQ
- Error monitoring (Sentry) + audit logs
- AI chat assistant (FAQ + compliance Q&A)

## Phase 3 — Enterprise (Weeks 11+)
- Procore/Autodesk integrations
- SOC2 controls + SSO (Okta/Azure AD)
- Data warehouse export (Snowflake/Redshift)
- Metabase/Tableau embedded analytics
- Advanced permissions & field-level RBAC
